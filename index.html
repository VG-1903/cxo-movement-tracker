CXO Movement Tracker

Daily-updated feed of CEO & CXO appointments, promotions and exits across BFSI, Education, Pharma, Healthcare and Corporate — parsed automatically from public news headlines. Free JSON API + drop-in widget.

Fetch example

const res = await fetch("https://cxo-movement-tracker.vercel.app/api/v1/pharma_latest.json");
const { records } = await res.json();
const indiaMoves = records.filter(r => r.region === "India").slice(0, 10);

Queryable API (Supabase)

For server-side filtering, sorting and pagination over the full dataset, query the Supabase REST endpoint directly. Send the publishable key as both apikey and Authorization: Bearer. It is read-only — writes are rejected.

const SUPABASE = "https://ovcjcdzabuavspbqiqbr.supabase.co/rest/v1";
const KEY = "sb_publishable_fMn8ipZjzvY3az3MP4TbGg_MSyoXVw7";

// newest 20 pharma moves in India
const res = await fetch(
  `${SUPABASE}/moves_feed?sector=eq.Pharma®ion=eq.India` +
  `&order=date.desc&limit=20`,
  { headers: { apikey: KEY, Authorization: `Bearer ${KEY}` } }
);
const rows = await res.json();

Useful filters

GoalQuery string
One sector?sector=eq.BFSI
India only?region=eq.India
Only exits?movement=in.(Resignation,Retirement)
Since a date?date=gte.2026-01-01
Company search?company=ilike.*pharma*
CEOs only?role_group=eq.CEO
Corporate CMOs?sector=eq.Corporate&role_group=eq.CMO
Sort + paginate?order=date.desc&limit=20&offset=40

Combine any of them with &. Full syntax: PostgREST operators (eq, neq, gte, lte, in, ilike).

Embed the widget on your site

One script tag — no build step, no dependencies. It renders the latest movements for the sector you pick (styles are isolated in a shadow root, so it can't clash with your CSS):

<script src="https://cxo-movement-tracker.vercel.app/embed.js"
        data-sector="pharma"          <!-- all | bfsi | pharma | healthcare | education | corporate -->
        data-role="ceo"               <!-- ceo | md | cfo | coo | cmo | chro | cto | cio |
                                           cdo | ciso | csuite | chairman | board | head |
                                           president — omit for all roles -->
        data-limit="8"
        data-region="India"           <!-- India | Global | omit for both -->
        data-theme="auto"             <!-- light | dark | auto -->
        data-title="Pharma leadership moves"></script>
data-role with data-sector="corporate" loads that role's own endpoint. For the other sectors it filters the 50 most recent moves of that sector client-side, so a rare role can return fewer rows than data-limit.
